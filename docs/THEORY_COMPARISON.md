# What is actually being tested

The project is **not** “apply Cayron CT to Cu–Al–Ni.” The experiment is a three-way prediction comparison.

## Identical inputs

All branches receive the same:

- parent and product phase definitions,
- measured lattice parameters,
- cell convention,
- verified correspondence,
- temperature/material state metadata.

## Branch A — Cayron Correspondence Theory

Predicts discrete correspondence variants/operators from cosets/double cosets, Type-I/II transformation twins from parent two-fold symmetries, A/M metric compatibility through CMC, IPS shear through SMC, and full A/M/M compatibility through the shear/shear relation.

## Branch B — classical PTMC

Starting from lattice deformation plus a lattice-invariant shear/twin system, predicts the macroscopic invariant-plane strain, habit plane, shape strain and orientation relationship. It must remain algorithmically independent of CT so agreement is meaningful.

## Branch C — Ball–James / cofactor theory

Builds the stretch wells \(SO(3)U_i\), solves rank-one connections, evaluates \(\lambda_2=1\) and CC1–CC3, and tests all-twin-fraction compatibility.

## Experimental observables

Do not fit and test on the same quantity. Candidate observables include:

- daughter orientation / variant identity,
- neighboring misorientation/operator identity,
- M/M boundary trace,
- A/M habit-plane trace,
- twin shear where independently measurable,
- morphology and variant fractions,
- hysteresis/reversibility only as secondary correlative outcomes because defects and kinetics also matter.

## Residuals

Keep residuals separate: orientation angle, axis error, trace error, CMC distance, \(|\lambda_2-1|\), CT \(\varepsilon\), cofactor residuals. Do not manufacture one “winner score.”
