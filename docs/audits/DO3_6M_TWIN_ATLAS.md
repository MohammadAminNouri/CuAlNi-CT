# DO3 -> 6M operator/twin atlas: CT versus Ball-James/Mallard

## Scope

This is the first theory-comparison layer built on top of the truth-locked
DO3 -> 6M reference branch.

It asks a narrow question:

> For every exact intervariant relation generated by the eight CT double-coset
> operators, do Cayron's correspondence/metric twin formulas reproduce the
> same M/M compatibility geometry as the independent Ball-James/Mallard
> rank-one construction?

The answer is tested numerically; it is not assumed.

The James-Hane Cu-14 wt% Al-4 wt% Ni lattice parameters are used only as a
source-rounded reproducibility benchmark. None of the shear values below are
universal Cu-Al-Ni constants.

## Independent mathematical routes

### Cayron CT route

For a parent reflection, CT gives a Type-I transformation twin. In the package
convention `u_M = C_M_from_A u_A`, the rational K1 plane is obtained by
inverse-transpose plane mapping. Cayron 2026 then gives the metric-dependent
shear magnitude and eta1 direction from the intercorrespondence matrix
(Cayron, Acta Materialia 316 (2026) 122399, Eqs. 19-21).

For a parent proper twofold rotation, CT gives a Type-II transformation twin.
The rational eta2 axis is inherited by correspondence, while the shear
magnitude and irrational K2 plane depend on the martensite metric
(Cayron 2026, Eqs. 22-25).

For parent n-fold rotations with n != 2, CT does not supply a perfectly
compatible Type-I/II plane from that symmetry alone; such operators are kept
only as weak-junction candidates at this stage.

### Ball-James/Mallard route

For symmetry-related stretch variants

    U_j = Q U_i Q^T

with `Q` a parent 180-degree rotation, the independent rank-one condition is

    R U_i - U_j = a ⊗ n.

James & Hane (Acta Materialia 48 (2000), Eq. 15-17) give the two Mallard
solutions (Type I and Type II). Chen et al. (JMPS 61 (2013), Eqs. 8-10)
give the same Type-I/Type-II domain construction and clarify that a compound
case occurs when two distinct parent twofold transformations relate the same
pair of stretch variants.

No CT plane or direction is passed into the Mallard solver.

## Coordinate bridge required for a fair comparison

A direct comparison of the raw vectors would be wrong.

In the Ball-James rank-one equation:

- `n` is a reference-configuration interface normal;
- `a` is the shear vector in the deformed/current configuration.

The CT object `plane_a` is a parent reciprocal covector, so it is converted to
a physical parent reference normal before comparison with `n`.

The CT object `direction_a` is stored as a parent reference direct direction.
Therefore it is first pushed through the target stretch `U_j` before comparison
with Ball-James `a`.

The code tests both conversions explicitly.

## Truth-locked operator classification

For the deterministic double-coset numbering of this repository:

| Operator | Classification | Exact stretch-pair relations | Meaning |
|---|---|---:|---|
| O0 | neutral | 0 | identity/self relation; zero-shear subgroup symmetries are excluded |
| O1 | compound | 1 | same stretch pair generated by two distinct parent twofold axes |
| O2 | compound | 1 | same stretch pair generated by two distinct parent twofold axes |
| O3 | weak candidate | 0 | non-twofold proper rotation content; no exact Type-I/II claim |
| O4 | Type-I/Type-II | 2 | two symmetry-equivalent exact stretch-pair relations |
| O5 | weak candidate | 0 | non-twofold proper rotation content |
| O6 | weak candidate | 0 | non-twofold proper rotation content |
| O7 | Type-I/Type-II | 2 | two symmetry-equivalent exact stretch-pair relations |

This gives six nontrivial exact reference-to-target stretch relations in the
selected reference-variant view.

Compound classification is NOT assigned merely because a double coset contains
both a reflection and a twofold operation. It is assigned only when two
distinct parent 180-degree rotations generate the same `U_j` from the same
`U_i`, consistent with the Ball-James/Chen definition.

## Benchmark shear amplitudes

Using the rounded James-Hane Table-4 Cu-Al-Ni lattice parameters, the
computation-derived shear amplitudes are:

- O1: 0.07709383077395
- O2: 0.19892147651004
- O4: 0.18908990849744
- O7: 0.38548856778794

For each exact relation, CT Type I, CT Type II, Mallard Type I, and Mallard
Type II give the same shear magnitude to numerical roundoff.

Again: these values belong to this benchmark metric only.

## What is verified

For every one of the six exact reference-to-target relations the automated
tests require:

1. CT Type-I shear == Mallard Type-I shear;
2. CT Type-II shear == Mallard Type-II shear;
3. CT Type-I shear == CT Type-II shear for the same twofold relation;
4. CT K1 parent plane == Mallard Type-I reference interface normal;
5. `U_j` times the CT Type-I reference shear direction == Mallard Type-I
   deformed shear direction;
6. CT K2 parent plane == Mallard Type-II reference interface normal;
7. `U_j` times the CT Type-II reference shear direction == Mallard Type-II
   deformed shear direction;
8. the Mallard rotation is orthogonal with determinant +1;
9. the rank-one equation residual is at numerical roundoff.

This is a substantially stronger test than merely obtaining the same twin
shear magnitude.

## What is NOT yet claimed

This atlas does not yet say which mathematically possible twin is selected in
a real Cu-Al-Ni microstructure.

It also does not yet calculate the rational weak planes for O3/O5/O6, because
that requires the weak-plane construction and its tolerance/ranking choices.

The next experimental-theory layer is:

- calculate EBSD-predictable disorientations and junction-plane traces;
- compare observed variant boundaries against O1-O7;
- then combine M/M compatibility with CMC/SMC A/M compatibility and the
  Cayron shear/shear supercompatibility residual.
